This document provides canonical, byte-for-byte hexadecimal frames verified against the reference RLP v1 encoder and decoder.

## 1. HELLO Frame (Type 1)

Client initiates session with protocol version `1`, device ID `"d1"`, credential `"k"`, and empty capabilities:


| `04` | `01` | Version | `1` |

| `08–10` | `00 01 6b` | Credential (`lp16`) | Length 1, `"k"` |
| `11–12` | `00 00` | Capabilities (`lp16`)| Length 0 |
