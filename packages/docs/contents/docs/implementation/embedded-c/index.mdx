# Embedded C Client Guide

This guide explains how to implement a memory-safe, zero-copy RLP Version 1 client in C for resource-constrained microcontrollers such as ESP32, STM32, nRF52, and RP2040.

---

## 1. Framing Header Parser (`rlp_frame.h`)

On microcontrollers, casting raw byte pointers directly to C `struct` pointers can cause hardware faults due to memory alignment constraints (e.g. ARM Cortex-M0/M3 unaligned access faults).

RLP provides a safe, standalone C header (`examples/c/rlp_frame.h`) that safely reads fields byte-by-byte:

```c
#ifndef RLP_FRAME_H
#define RLP_FRAME_H

#include <stdint.h>

/* Header is four bytes. Never cast an unaligned network buffer to a struct. */
#define RLP_HEADER_SIZE 4

static inline uint16_t rlp_u16be(const uint8_t *p) {
    return ((uint16_t)p[0] << 8) | (uint16_t)p[1];
}

/**
 * Returns 1 only when a complete, bounded frame is available in the buffer.
 *
 * @param p Pointer to the buffer
 * @param available Number of available bytes in buffer
 * @param max Maximum allowed payload size
 * @param type Output pointer for frame type
 * @param flags Output pointer for frame flags
 * @param length Output pointer for payload length
 */
static inline int rlp_frame_header(const uint8_t *p, uint32_t available, uint16_t max,
                                   uint8_t *type, uint8_t *flags, uint16_t *length) {
    if (available < RLP_HEADER_SIZE) return 0;

    *type   = p[0];
    *flags  = p[1];
    *length = rlp_u16be(p + 2);

    return *length <= max && available >= (uint32_t)RLP_HEADER_SIZE + *length;
}

#endif /* RLP_FRAME_H */
```

## 2. Encoding Telemetry in C

Because RLP frame headers are a fixed 4 bytes, encoding a telemetry sample requires zero dynamic allocations. You can assemble frames in a small stack buffer.

### Example: Encoding a FLOAT32 Sensor Reading

```c
#include <string.h>
#include <stdint.h>
#include "rlp_frame.h"

#define PACKET_TYPE_DATA 3
#define VALUE_TYPE_FLOAT32 10

/**
 * Encodes a FLOAT32 sample on a given channel without timestamp.
 * Total frame size: 4 (header) + 2 (channel) + 1 (type) + 4 (float) = 11 bytes.
 */
int encode_telemetry_float(uint8_t *out_buf, uint16_t channel, float value) {
    // 1. Frame Header (4 bytes)
    out_buf[0] = PACKET_TYPE_DATA;
    out_buf[1] = 0x00;             // Flags: no timestamp
    out_buf[2] = 0x00;             // Length high byte
    out_buf[3] = 0x07;             // Length low byte (7 bytes payload)

    // 2. Channel (u16be)
    out_buf[4] = (uint8_t)(channel >> 8);
    out_buf[5] = (uint8_t)(channel & 0xFF);

    // 3. Value Type
    out_buf[6] = VALUE_TYPE_FLOAT32;

    // 4. Value (IEEE-754 single precision float, big-endian)
    uint32_t float_bits;
    memcpy(&float_bits, &value, sizeof(float));

    out_buf[7]  = (uint8_t)(float_bits >> 24);
    out_buf[8]  = (uint8_t)(float_bits >> 16);
    out_buf[9]  = (uint8_t)(float_bits >> 8);
    out_buf[10] = (uint8_t)(float_bits & 0xFF);

    return 11; // Total bytes to write to socket
}
```

## 3. Handling Incoming Commands and ACKs

When the server issues a `COMMAND`, the microcontroller reads the 4-byte command ID and channel, executes the action (e.g. toggling a GPIO pin), and writes an `ACK` frame back:

```c
#define PACKET_TYPE_COMMAND 5
#define PACKET_TYPE_ACK     6

void handle_incoming_command(int socket_fd, const uint8_t *payload, uint16_t length) {
    if (length < 8) return; // Command header requires at least 4 (id) + 2 (ch) + 1 (type) + 1 (val)

    uint32_t cmd_id = ((uint32_t)payload[0] << 24) |
                      ((uint32_t)payload[1] << 16) |
                      ((uint32_t)payload[2] << 8)  |
                      (uint32_t)payload[3];

    uint16_t channel = rlp_u16be(payload + 4);
    uint8_t val_type = payload[6];
    uint8_t val      = payload[7];

    uint8_t status = 0; // OK

    if (channel == 2 && val_type == 1 /* BOOL */) {
        set_gpio_relay_state(val == 1);
    } else {
        status = 2; // UNSUPPORTED
    }

    // Send ACK frame (9 bytes total)
    uint8_t ack_frame[9];
    ack_frame[0] = PACKET_TYPE_ACK;
    ack_frame[1] = 0x00; // Flags
    ack_frame[2] = 0x00;
    ack_frame[3] = 0x05; // Length = 5

    ack_frame[4] = (uint8_t)(cmd_id >> 24);
    ack_frame[5] = (uint8_t)(cmd_id >> 16);
    ack_frame[6] = (uint8_t)(cmd_id >> 8);
    ack_frame[7] = (uint8_t)(cmd_id & 0xFF);
    ack_frame[8] = status;

    send(socket_fd, ack_frame, 9, 0);
}
```

## 4. Best Practices for Microcontrollers

1. **Static Buffer Allocation:** Use static ring buffers for incoming TCP streams rather than `malloc()`.
2. **Bounds Checking:** Never read beyond `available` bytes. Pass the buffer limit to `rlp_frame_header()`.
3. **Keep-Alive Scheduler:** Implement a hardware timer that emits `PING` packets every 30–60 seconds if no telemetry has been sent.
